Mobile developer from Kerala, India, working across **React Native / Expo**, **native Kotlin**, and **LLM-powered backends**. I've shipped e-commerce and enterprise HRMS apps, and I build side projects around real-time voice, geospatial telemetry, and grounded AI (RAG).
